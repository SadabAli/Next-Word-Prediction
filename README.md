# 🧠 Next Word Prediction using LSTM

This project demonstrates a simple **Next Word Prediction** model using an LSTM (Long Short-Term Memory) network built with TensorFlow and Keras. The model is trained on a paragraph about Islam to learn sentence structure and predict the next word based on previous words.

---

## 📌 Objective

To build a text generation model that predicts the next word in a sentence using deep learning techniques. This is commonly used in applications like:
- Auto-complete
- Chatbots
- Smart writing assistants

---

## 📚 Dataset

A small paragraph on Islam is used as the dataset. The text is tokenized into words, converted into sequences, and padded for training.

Example input:
> *"Islam is a monotheistic Abrahamic religion founded on the teachings of the Prophet Muhammad..."*

---

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- Natural Language Processing (NLP)
- LSTM Neural Networks
